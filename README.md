# 💱 TypeScript Döviz Çevirici (CLI Currency Converter)

Bu proje, modern **TypeScript (NodeNext)** ve **Node.js** mimarisi kullanılarak geliştirilmiş, terminal üzerinden anlık döviz dönüşümü yapmayı sağlayan interaktif bir CLI (Command Line Interface) uygulamasıdır.

## 🚀 Özellikler
* **Modern ESM Yapısı:** En güncel TypeScript modül yönetim kuralları (`verbatimModuleSyntax`, `nodenext`) ile yazılmıştır.
* **Strict Type Checking:** `noUncheckedIndexedAccess` aktiftir; olası `undefined` hataları kod derlenmeden yakalanır.
* **Kullanıcı Etkileşimi:** `readline-sync` ile terminal üzerinden dinamik veri alımı gerçekleştirilir.
